# Distribution Package Contract & `.distignore` Specification

This document defines the distribution archive contents, forbidden development leaks, and exclusion rules enforced by `tools/release/validate-package.mjs` and `.distignore`.

Governed by **ADR-0010: Two-Pipeline CI/CD and Release Readiness Architecture**.

---

## 1. Package Content Contract

The distribution archive generated by `npm run release:build` must strictly conform to the following contract.

### 1.1 Required Distribution Contents

Every release ZIP must contain:

- `{plugin-slug}/` as the sole top-level archive directory.
- `{plugin-slug}/{plugin-slug}.php`: Main plugin entry file with metadata headers.
- `{plugin-slug}/vendor/autoload.php`: Composer production autoloader (with zero dev-dependencies).
- `{plugin-slug}/src/`: Runtime PHP classes across Framework, Backend, and Frontend Bridge.
- `{plugin-slug}/build/`: Compiled production JavaScript and CSS assets.
- `{plugin-slug}/readme.txt`: WordPress-standard plugin readme with `Stable tag:` matching the release version.
- `{plugin-slug}/uninstall.php`: Lifecycle uninstallation handler.

### 1.2 Forbidden Development Artifacts

The package validator strictly fails if any of the following leak into the archive:

- **Version Control & Workflows:** `.git/`, `.github/`.
- **Editor & Agent Config:** `.cursor/`, `.agents/`, `.codex/`.
- **Development Tooling & Tests:** `node_modules/`, `tools/`, `tests/`, `docs/`.
- **Configuration Files:** `.env*`, `package.json`, `package-lock.json`, `composer.json`, `composer.lock`, `tsconfig.json`, `phpunit.xml*`, `phpcs.xml*`, `phpstan.neon*`, `webpack.config.js`.
- **Markdown & Meta Files:** `AGENTS.md`, `MANIFEST.md`, `CHANGELOG.md`, `.distignore`.
- **Uncompiled Source Assets:** Raw TypeScript/SCSS in `src/frontend/apps/*/react/` that has already been compiled into `build/`.

## 2. `.distignore` Rules

The root `.distignore` file dictates archive packaging. The in-tree parser `tools/release/lib/distignore.mjs` interprets these rules:

```text
# Git & CI/CD
.git/
.github/

# Development Tools & Instructions
.cursor/
docs/
tests/
tools/
node_modules/

# Development Configurations
.editorconfig
.gitignore
.distignore
.env*
composer.json
composer.lock
package.json
package-lock.json
tsconfig.json
phpcs.xml*
phpstan.neon*
phpunit.xml*
playwright.config.ts
jest.config.js
webpack.config.js
redocly.yaml

# Project Documentation
AGENTS.md
MANIFEST.md
CHANGELOG.md
```

---

## 3. Local Contract Validation

To test whether the current repository builds a compliant package:

```bash
# Build candidate package
npm run release:build

# Inspect contents and validate against contract
npm run release:validate
```
