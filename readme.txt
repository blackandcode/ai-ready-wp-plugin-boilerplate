Enterprise-grade WordPress plugin boilerplate designed for AI coding agents and human developers.

== Description ==

AI-Ready WP Plugin Boilerplate provides a modern, robust architecture for WordPress plugin development. It includes a tripartite app-centric domain model (Framework, Backend, Frontend Bridge), Gutenberg Block API v3 integration with Interactivity API, React 18 admin settings interface built with the WordPress Design System (WPDS), contract-first REST API endpoints, and a comprehensive five-tier testing pyramid.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/ai-ready-wp-plugin-boilerplate` directory, or install through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Access the plugin settings under the WordPress admin menu.
4. Full developer documentation and human-readable source code: https://github.com/wordpress-ai/ai-ready-wp-plugin-boilerplate
